# Advent of Code

Solutions to [Advent of Code](https://adventofcode.com/) puzzles.

## Years Covered

| Year | Days Solved | Notes |
|------|-------------|-------|
| 2015 | 25 | Part 1 and Part 2 |
| 2020 | 1 | Day 2 Part 1 |
| 2025 | 12 | Part 1 and Part 2 |

## Languages

- **Python** — primary language for all years
- **Rust** — select solutions for 2025 (days 2, 9, 12)
- **C** — select solutions for 2015 (day 20) and 2020 (day 2)

## Usage

```bash
# Python
python3 2025/1.py

# Rust
rustc 2025/12.rs -o day12 && ./day12

# C
gcc 2015/20.c -o day20 && ./day20
```
